# Cronograma del curso

Este es el plan de clase a clase del semestre 2026-1. El curso está organizado en bloques temáticos de 2 semanas cada uno; al final de cada bloque grande hay un **hito evaluativo** (parcial o proyecto).

También puedes consultar la [hoja de cálculo del calendario del curso](https://docs.google.com/spreadsheets/d/1DA5ggeCsvAdsqmjU7Y0btmJ6PPkmt0VNw3-F5lG_b2M/edit?usp=sharing) directamente.

| Semanas | Contenido | Hito evaluativo | Temas evaluados | Metodología |
|---|---|---|---|---|
| 1 - 2 | Análisis: notación Big O (O, Ω, Θ). Complejidad en el peor/mejor caso. | | | |
| 3 - 4 | Análisis: análisis de ciclos y estructuras de datos. Introducción a Fuerza Bruta. | | | |
| 5 - 6 | Fuerza Bruta: generación de permutaciones y combinaciones. | **Evento I (10%)** — Clase 6 | Fuerza bruta y análisis de complejidad | Parcial estilo competencia, en parejas |
| 7 - 8 | Greedy: el algoritmo voraz y criterios de ordenamiento (heaps). | | | |
| 9 - 10 | Greedy: casos de fallo y problema de la mochila fraccionaria. | **Evento II (10%)** — Clase 10 | Algoritmos greedy + análisis de complejidad | Parcial estilo competencia, individual |
| 11 - 12 | Backtracking: árboles de espacio de estados y recursión. | | | |
| 13 - 14 | Backtracking: técnicas de poda (pruning) y optimización. | | | |
| 15 - 16 | Backtracking: N-Reinas y laberintos. | **Evento III (15%)** — Clase 16 | Backtracking + análisis de complejidad | Parcial estilo competencia, individual |
| 17 - 18 | Dividir y Vencerás: descomposición y combinación (MergeSort). | | | |
| 19 - 20 | Dividir y Vencerás: árboles de recurrencia y estimación. | | | |

| 23 - 24 | Programación Dinámica: introducción y memoization (top-down). | | | |
| 25 - 26 | Programación Dinámica: tabulation (bottom-up) y reconstrucción de soluciones. | | | |
| 27 - 28 | Programación Dinámica: problemas de optimización (mochila 0/1, Levenshtein). | | | |
