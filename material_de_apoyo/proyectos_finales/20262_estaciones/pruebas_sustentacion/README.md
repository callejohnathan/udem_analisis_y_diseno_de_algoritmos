# Instancias para la sustentación

Cada equipo recibe una variante (`variante_A`, `variante_B` o `variante_C`). Cada variante contiene las instancias `pequena`, `comuna` y `ciudad` con el mismo formato de archivos descrito en el notebook `practica_estaciones.ipynb`.

La red vial (`nodos.csv`, `aristas.csv`) y los parámetros (`parametros.json`) son los mismos de las instancias originales. Cambian la distribución de lotes (`lotes.csv`) y el histórico de incidentes (`incidentes.csv`).

Para ejecutar la solución sobre una variante, basta con apuntar la lectura de archivos a la carpeta correspondiente, por ejemplo `pruebas_sustentacion/variante_B/comuna`.
